# Education

Одностраничный сайт образовательной платформы: главная страница, информация о платформе, партнёры и каталог лекторов.

## Стек и версии

Версии указаны в `package.json`:

- React и React DOM — `^19.2.8`
- Vite — `^8.3.0`
- `@vitejs/plugin-react` — `^6.1.1`
- ESLint — `^10.10.0`
- JavaScript, ES modules, CSS
- Node.js — `^20.19.0`, `^22.12.0` или новее в поддерживаемых ветках, согласно требованиям Vite

`package-lock.json` фиксирует версии установленных пакетов.

## Установка и запуск

Требуется установленный Node.js и npm.

```bash
npm install
npm run dev
```

Для проверки и предпросмотра production-сборки:

```bash
npm run lint
npm run build
npm run preview
```

## Структура проекта

```text
public/                     Статические файлы, доступные по URL от корня сайта
src/
  assets/                   Импортируемые изображения и SVG
  components/
    About/                  Блок «О нас»
    Lectors/                Каталог, карточка и данные лекторов
    Main/                   Главный экран
    Navbar/                 Навигация
    Partners/               Блок партнёров
  styles/
    App.css                 Общие стили приложения
    index.css               Базовые стили
  App.jsx                   Сборка страниц и логика навигации
  main.jsx                  Точка входа React
index.html                  HTML-шаблон приложения
vite.config.js              Конфигурация Vite
eslint.config.js            Конфигурация ESLint
package.json                Зависимости и команды npm
package-lock.json           Зафиксированные версии зависимостей
```

## Данные и навигация

- Данные лекторов и их дисциплин, тарифов и профилей находятся в `src/components/Lectors/lectorsData.js`.
- Данные партнёров находятся в массиве `PARTNERS` в `src/components/Partners/Partners.jsx`.
- Текст остальных блоков задан непосредственно в JSX соответствующих компонентов.
- Статические изображения и иконки сайта находятся в `public/`; дополнительные ресурсы для импорта компонентами — в `src/assets/`.
- Навигация реализована в `src/App.jsx` через состояние React: пункты главной страницы прокручивают к секциям, а раздел лекторов отображается как отдельное состояние приложения. URL-роутера (например, React Router) в проекте нет.
