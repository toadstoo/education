# Инструкция по хранению фотографий лекторов в Yandex Cloud Object Storage

## 1. Что нужно сделать

Для загрузки фотографий лекторов с Yandex Cloud и их автоматического отображения на сайте используется публичное хранилище (Object Storage) Yandex Cloud.

Базовый URL, который настроен в коде:
```
https://storage.yandexcloud.net/ed-platform-lectors/
```

Код ожидает, что фотографии будут называться по ключу лектора в формате `<photoKey>.jpg`.

## 2. Создание бакета в Yandex Cloud

1. Зайдите в [Yandex Cloud Console](https://console.cloud.yandex.ru/)
2. Выберите сервис "Object Storage" (Yandex Cloud Storage)
3. Нажмите "Создать бакет"
4. Имя бакета: `ed-platform-lectors` (именно так, чтобы совпадало с URL)
5. Тип доступа: **Публичный** (public read) — это необходимо, чтобы браузер мог загружать фотографии по прямой ссылке
6. Остальные настройки можно оставить по умолчанию
7. Создайте бакет

## 3. Загрузка фотографий

Для каждого лектора в файле `src/components/Lectors/lectorsData.js` указан параметр `photoKey`. Например:

```js
{
  id: 'petrov-dmitry-sergeevich',
  fullName: 'Петров Дмитрий Сергеевич',
  photoKey: 'petrov-dmitry-sergeevich',
  ...
}
```

Соответственно, фотографию нужно загрузить с именем:

```
petrov-dmitry-sergeevich.jpg
```

Алгоритм загрузки:

1. Откройте созданный бакет `ed-platform-lectors` в Yandex Cloud Console
2. Нажмите "Загрузить объекты"
3. Загрузите JPG-файлы для каждого лектора (рекомендуемый формат: JPG/JPEG)
4. Размер рекомендуется: 400×500 или 500×600 (пропорции 4:5) — фотографии будут отображаться с обрезкой через `object-fit: cover`
5. Убедитесь, что файлы имеют публичный доступ (по умолчанию при публичном бакете они становятся доступными)

## 4. Проверка работоспособности

После загрузки фотография должна открываться по ссылке:

```
https://storage.yandexcloud.net/ed-platform-lectors/petrov-dmitry-sergeevich.jpg
```

Если ссылка открывается в браузере (показывает изображение) — всё настроено правильно. На сайте фотографии автоматически подгрузятся.

## 5. Замена/добавление новых фотографий

1. Загрузите новый файл с нужным именем в бакет (перезапись объекта заменит фото)
2. Если добавляете нового лектора — укажите его `photoKey` в `lectorsData.js`, загрузите соответствующий `.jpg` файл

## 6. Безопасность и рекомендации

- Бакет настроен как **публичный только для чтения** (чтение объектов доступно всем). Это нормально для отображения фото на публичном сайте
- Не загружайте в бакет конфиденциальные документы
- Рекомендуется сжимать изображения перед загрузкой для ускорения загрузки сайта
- При желании можно использовать формат `.webp` для оптимизации — в этом случае нужно будет чуть поправить код (заменить `.jpg` на `.webp`)

## 7. Что настроено в кодовой базе

- В `src/components/Lectors/LectorPhoto.jsx` реализована функция `getPhotoUrl()` для формирования ссылки; этот же компонент используется и в списке (`Lectors.jsx`), и на странице лектора (`LectorDetail.jsx`)
- Есть fallback на `photo-placeholder.svg`, если фото не загрузилось (например, файл ещё не загружен или имя не совпадает)
- Реализована обработка ошибки загрузки (`onError`) — автоматически подставляется плейсхолдер

Код готов к работе. После выполнения шагов 1-3 фотографии отобразятся автоматически!
